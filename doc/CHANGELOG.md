# Changelog of aha-aql.spec.md

- 2026-11-24: Version 0.5.0. Six MILESTONE sections are new. They are the scaffold milestone 0.0.0 and the milestones 0.1.0 to 0.5.0, with three to seven behaviors each, in the order of their dependencies. The specification has 26 behaviors, and with milestones each translation pass has a small part of them. No behavior, type, interface, invariant or example changed.
- 2026-11-24: Version 0.4.0. The new behavior custom-fields reads the custom field definitions of the account. A statement can now read a custom field as custom.<key> in SELECT, WHERE, GROUP BY and ORDER BY, and UPDATE can set it. The maintainer asked for reading and writing on 2026-11-24. Touched as a consequence: the types FieldName, EntityDef and MaxListed, the new types CustomField, CustomKind and TextList, the list rule of AhaAPI and the fixture of FakeAha; the behaviors query, tool-registration, read-statement, describe-statement, insert-statement, update-statement, delete-statement, parse-statement, entity-catalog, resolve-names, plan-fetch, convert-record, evaluate-condition, check-write-values, write-request and error-messages (N02, W16 and W17 changed; N04 to N07, W31, W32 and X05 new); three PRECONDITIONS and four INVARIANTS are new, and three INVARIANTS have a new text.
- 2026-11-24: Version 0.3.1. Three small changes follow the review of the open questions. The author line has a new address, the User-Agent has the address of the project, and load-configuration answers an unknown first word with the new message G12.
- 2026-11-13: Version 0.3.0. The environment is now a regular source of settings: a new invariant lists every variable that the server reads, and an option takes precedence. load-configuration also reads AHA_DEFAULT_PRODUCT and AHA_READ_ONLY and ignores AHA_API_KEY in http mode; aha-request uses the proxy and the trust store of the environment. The reason is the use in a sandbox that gives credentials through the environment and sends all traffic through a proxy.
- 2026-11-13: Version 0.2.0. The specification now describes a new MCP server, mcp-server-aha-aql, on the template mcp-server, and no longer an amendment of aha-studio. New are manual mode, configuration from options and two environment variables, an account per request in http mode, and own HTTPS requests to Aha!. The operator profile, writes by predicate, custom field references, writes on products and DELTA are removed; the file was aha-studio-aql.spec.md until 0.1.0.
- 2026-11-13: Version 0.1.0. First version: the amended AQL of aha-studio on the base version 0.12.0. It has the two MCP tools query and execute, the entity catalog, a read path that evaluates every condition on complete records, and write statements that change one record found by its id. It follows the analysis of 2026-11-11 and the test results of 2026-11-12, and it is the input for patches to the upstream project.
